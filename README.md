# PixelBean · 拼豆图纸生成器

把任意图片转换为**拼豆像素图纸**：每个像素格对应一颗豆子，标注该用哪个品牌色号体系下的哪颗豆，并统计每种色号需要多少颗（购物清单）。纯前端、本地优先，支持打印图纸与 PNG 导出。

> 目录名 `PixelBean` 取自"像素 (Pixel) + 拼豆 (Bean)"。

## 三 Agent 交接约定（重要）

1. **共享仓库即唯一事实来源**：DeepSeek 产出的 docs/ 与 data/ 是所有下游实现的"契约"。Codex / Claude Code 不得自行发明与 docs 冲突的数据结构或模块边界；若有冲突，先改 docs 再改代码。
2. **许可证红线**：禁止从 `docs/00` 中标注为 AGPL/GPL/无证/来源不明 的仓库复制代码或色表数据（可参考思路）。只有标注"可复用"的数据/代码才允许照搬（见 `docs/00` 与 `docs/04`）。
3. **原创代码**：本项目自身代码全部原创；色表数据按 `docs/04` 指定的来源与许可证引入并在数据内记录 provenance。

## 技术速览（详见 docs/02–03）

- Vite + React + TypeScript，纯前端静态部署（GitHub Pages / Vercel / 任意静态托管）。
- 颜色匹配：CIEDE2000（色板加载时预计算并缓存 Lab 值），不用 RGB 欧氏距离。
- 降采样：linear-RGB 面积平均（默认）/ 主导色，两种模式；网格语义"长边格数 + 锁宽高比"，绝不非均匀拉伸。
- 渲染：整图 Canvas 绘制 + 瓦片式标注层，避免数千 DOM 节点。
- 转换管线为 DOM-free 纯模块，配确定性单元测试（golden fixture）。

## v1.1 功能速览

- 目标模式一键预设：照片 / 卡通插画 / 线稿 / 像素表情包；手动改动自动进入“自定义”。
- 工艺后处理：孤立噪点清理 → 暗部简化 → 智能限色（色相族分层 ≤K）→ 1px 自动描边。
- 内置色板：MARD 291、Perler Standard 103（社区旧表）、Hama Midi 92（社区旧表）。
- 底板预设新增 116×116；统计/CSV/PNG/打印沿用 v1 结构。

## 移动端适配速览

- 桌面/平板/手机/极小屏四档断点；手机使用“图片参数 / 图纸 / 用量导出”三段底部导航。
- 图纸支持全屏查看、单指平移、双指捏合、双击缩放、点按查看格信息。
- 无横向页面溢出；统计表内滚；输入控件 ≥16px；支持 iOS 安全区与 `100dvh`。

## v1.2 速览（docs/18、docs/19）

- **P0 视图修复**：屏幕预览画布改为“视口化”（位图恒定 + 可见区裁剪），消灭 100/200 格大图缩放被自动 fit 复位、位图超上限空白、无光标锚点等根因；补齐桌面平移可用性（空格拖拽/光标/滚轮锚定）；移动端统一安全区/高度变量、z 序表、底部工具条网格化。
- **P1 算法优化**：二阶孤立噪点清理（单格删除 + 2..N 连通合并）、暗部简化“1~2 层收敛规则”、降采样阶段小特征保护（细线/眼睛/点缀 + 贯穿后处理的保护掩码）、主色优先的智能限色（≥5% 用量主色必保 + 同色相自动合并）。算法仍纯前端、DOM-free、确定性、不引入无效色号。
