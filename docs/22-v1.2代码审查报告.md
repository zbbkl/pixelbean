## 6. 残余风险（P2 记入不修）

1. **非族内最大主色不强制保留**（P2-4）：同 hue 族内「用量 ≥5% 但非族内最大」的色号在 `clusterLimitV2` 中不进入 `final`，会被 `nearestInSet` 就近并掉。要修需按 §5.3 `for idx in protectedSet: final.add(idx)` 把 mains 显式入 final，会改变 multi-main 同族输入的输出，需连带重跑 golden 审阅；当前主流（黄 60% 单主色）不受影响。**建议下一迭代评估是否落地。**
2. **无真机 iOS/微信验收**：`env(safe-area-inset-*)` 分支靠 CSS 变量 + 兜底规则覆盖，桌面 Chromium 无法复现真机 Home 条/刘海数值；建议真机抽查 iOS Safari 双击与微信 http 直连。
3. **`viewSession` 为模块级可变状态**（`PreviewCanvas.tsx:41`）：主预览/全屏共享 fit 会话是 docs/18 Q8 的设计意图，但非 React 生命周期管理，若未来出现第三处挂载点需复查。
