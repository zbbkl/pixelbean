## 实现要点

- **四档断点**：≥1024 保持三栏；768–1023 两栏且左侧参数可折叠；480–767 单栏 + 底部三段导航（图片参数/图纸/用量导出）；≤480 紧凑间距与窄按钮排布。
- **状态保留**：切换三段只改 DOM 显示状态，`source/settings/pattern/stats` 仍在同一个 reducer state 中；Playwright 实测改 K 后切走再回参数，模式仍为“自定义”。
- **画布交互**：新增 Pointer Events 多点手势：单指平移、双指捏合缩放、双击放大/复位、无拖动 tap 显示格信息；底部移动工具栏提供 −/＋/适应/全屏/色号/格线；全屏图纸覆盖整个 viewport。
- **移动端防溢出**：`overflow-x:hidden`、面板 `min-width:0`、长内容内部滚动；统计表 `min-width` + 内部横向滚动 + 首列 sticky。
- **iOS/WebView**：`viewport-fit=cover`、`100dvh` 回退 `100vh`、底栏 `env(safe-area-inset-bottom)`、输入控件字号 16px、交互控件 `touch-action:manipulation`、画布区 `touch-action:none` 与 `overscroll-behavior:contain`；未使用 `user-scalable=no`。
- **导出与打印**：移动端将导出组放到“用量导出”段；≤480 隐藏仅打印用 ghost 按钮；`@media print` 规则保持不受影响。

## 偏差与残余

- 当前仓库 `npm test` 为 109 而非文档中写的 108；本任务保持 109 未动。
- 双指捏合使用 Pointer Events 手写几何；浏览器未把真实触屏“惯性/橡皮筋”作为验收项，只验证缩放状态变化。
- 微信 iOS 对纯 HTTP 页面的平台提示无法在桌面 Chromium 完全复现，已在任务说明中按平台限制记录；页面本身不依赖 history/Cookie。
- 极小屏 320px 下统计表/导出区可完整操作，但部分面板横向空间紧凑；建议真机微信与 iOS Safari 各做一次最终人工抽查。
