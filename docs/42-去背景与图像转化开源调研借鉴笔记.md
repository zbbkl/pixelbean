## 1. 去背景（background removal / matting）项目

| 项目 | ★ | 栈 | 许可证 | 算法路线 | 可借鉴 |
|---|---:|---|---|---|---|
| [danielgatis/rembg](https://github.com/danielgatis/rembg) | 24.7k | Python | **MIT ✅ 可学** | ONNX 深度学习 matting（u2net / isnet / birefnet / SAM…）+ **alpha matting 精修** | **`matting.py`（软边 alpha matting 后处理）**、`test_decontaminate.py`（边缘**去色污染**）、`sessions/base.py`（模型抽象） |
| [imgly/background-removal-js](https://github.com/imgly/background-removal-js) | 7.3k | TS（浏览器） | **AGPL-3.0 ❌ 不可抄** | 浏览器内 ONNX Runtime（WebGPU/WASM）+ ISNet 量化模型 | **仅架构**：worker 内推理、**分块下载模型 + 进度**、**mask 上采样回原图**、能力检测、codec 抽象、模型量化（fp16/quint8） |
| [rAum/grabcut](https://github.com/rAum/grabcut) | — | C++ | **无许可证 ⚠️** | 经典 GrabCut（颜色 GMM + 图割迭代） | 仅思路；**GrabCut 算法公开**，可自行实现 |
| OpenCV `grabCut` | — | C++ | **BSD-3 ✅** | 同上（工业级参考实现） | 算法契约与 trimap/rect 初始化方式 |

**关键洞察（对本项目最关键）**
1. **成熟的"好"去背景 = 学习式 matting**（u2net/isnet/SAM/BiRefNet）。它们对「白底白身」有效，因为用的是**语义**而非颜色。但代价是：模型 4–176MB、需 ONNX/WASM 运行时、训练数据/权重许可需单独核。**与 PixelBean「纯前端、零依赖、静态部署」冲突**；且最好的浏览器封装是 AGPL。
2. **轻量确定性路线**的公开构件都在，且多为 MIT：
   - **alpha matting**（rembg `matting.py`，MIT）：把粗掩码 + **trimap** 精修成带 alpha 的软边 → **正是本类"柔边"要的东西**。
   - **color decontamination**（rembg，MIT）：去掉边缘残留的背景色（白边），避免抠完主体带一圈白。
3. **单一颜色判据必然失效**（印证 `docs/39`）：颜色空间里「白身≈白底」，必须引入**空间结构/语义线索**。轻量可用的结构线索是 **saliency** 与 **多尺度梯度/引导滤波**（见 §3）。

**关键洞察**：图像转化侧的"好效果"来自三件事——① **保结构的降采样**（边缘/特征引导，而非纯均值）；② **感知色空间的量化**（Oklab/ΔE，而非 RGB 欧氏）；③ **色块后处理**（合并/纯净度）。PixelBean 已在 ②③ 上对齐（CIEDE2000 + 连通域合并），差距主要在 ①（见 docs/34）。**k-means 量化**是多数项目的核心，但 PixelBean 的约束（**色板固定为品牌色号**）使其等价于"**受限色板最近邻匹配**"，因此 k-means 只适合做**中间层**（先聚类再映射色号），不宜直接替代匹配。

## 3. 可自实现的经典算法（公开知识，与许可证无关）

> 这些是论文/教科书算法，**按公式自实现**即可，不受第三方仓库许可证约束。

**抠图 / 主体分割**
- **GrabCut**（Rother et al., 2004）：颜色 GMM 建前景/背景模型 + GraphCut 迭代；可用矩形/trimap 初始化。
- **Alpha matting**：Levin 闭式解（2006）、KNN matting（Chen 2013）、Guided feathering。输入 = trimap（前景/背景/未知），输出 = 软 alpha。**软边关键**。
- **Color decontamination**：估计前景真实色 F = (I − (1−α)B)/α，去边缘背景污染。
- **Saliency**：spectral residual（Hou & Zhang, 2007，**一次 FFT**）、FT/AC/HC/RC。**白底白身的重要补充线索**。
- **SLIC superpixel**：超像素分割 → 以超像素为最小单元做前景/背景标注，抗碎。

**保边滤波 / 掩码精修**
- **Guided filter**（He et al., 2010）：O(N)、确定性、保边；把粗糙掩码以原图为引导做保边精修 → 掩码贴合软边。
- **Bilateral filter**：保边平滑；对小特征有保护作用（可用于降采样前的边缘保持）。
- **Multi-scale structure gradient**：`mean_s(p) vs ring_s(p)` 的 ΔE 脊（docs/41 §B.1）——对软轮廓有效。

**颜色量化 / 抖动**
- k-means / k-medoids、median-cut、**Wu 量化**、octree；感知距离用 Oklab/CIEDE2000。
- 抖动：Floyd–Steinberg、ordered(Bayer)、blue-noise（PixelBean 已有 FS 可选）。

## 4. 对 PixelBean 的落地结论（结合纯前端 + 红线）

### 4.1 不采用（并说明理由）
- **AI matting（u2net/isnet/SAM/BiRefNet）**：与「纯前端零依赖、静态部署、首屏体积」冲突；模型许可需单核；唯一成熟的浏览器封装（imgly）是 **AGPL** → 不引入。可保留为「**可选增强/未来项**」，并在 UI 注明需下载模型。

### 4.2 B（稳健去背景）的推荐技术阶梯（全部确定性、零依赖、可自实现）
| 阶 | 技术 | 作用 | 参考（可学） |
|---|---|---|---|
| B-1 | **多尺度结构梯度屏障**（docs/41 §B.1） | 让洪水在**软轮廓脊**处停下（补单像素梯度失效） | 自实现；概念同 guided/edge-aware |
| B-2 | **Guided filter 掩码精修** | 把粗掩码贴到软边，O(N) 确定性 | [lisabug/guided-filter](https://github.com/lisabug/guided-filter)（**MIT**）/ He 2010 论文 |
| B-3 | **Saliency 主体线索**（spectral residual，一次 FFT） | 白底白身时提供**非颜色**的主体证据；与洪水结果做交集/种子 | Hou & Zhang 2007 **论文**自实现（[uoip/SpectralResidualSaliency](https://github.com/uoip/SpectralResidualSaliency) 无证 ⚠️ 仅看思路） |
| B-4 | **Color decontamination** | 去主体边缘残留白边 | [danielgatis/rembg](https://github.com/danielgatis/rembg) `matting.py` **MIT** |
| B-5 | **Alpha matting（闭式/KNN）** | 真正软边；需解稀疏线性系统 → 建议**降采样求解 + 上采样**控制成本 | rembg（MIT）/ 论文自实现 |
| — | **可靠度兜底（A.2）** | 任一步不可信 → 回退不抠（保证绝不劣于上一版） | docs/41 §A.2 |

> 建议实现顺序：**B-1 → B-2 →（测试）→ B-4 →（视门禁）B-3/B-5**。每步都过 `docs/41 §B.4` 门禁 G1–G7，未过则保持 `removeBackground=false`。

### 4.3 对转化管线（非去背景）的借鉴
- **降采样**：引入**边缘/方差引导**（docs/34 §5.1）是当前最大差距，pixel-mosaic 的「边缘检测 → 像素化 → 网格优化」三段式架构值得对齐（保持 PixelBean 现有 `downsample/features/match/post` 模块边界）。
- **量化**：k-means 仅作**中间聚类**（可选），最终仍需映射到品牌色号（本项目契约）。
- **架构纪律**：pixel-mosaic / rembg 都做到了「**算法纯函数 + 独立测试**」；rembg 更是**每个模型一个 session 类**——与 PixelBean「DOM-free 纯模块 + golden fixture」一致，继续保持。
