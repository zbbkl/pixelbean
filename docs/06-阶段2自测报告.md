## 与 docs 的偏差/实现说明

- `ConvertOptions` 增加可选 `contain` 字段，用于方形底板 contain + 空行语义；无 contain 时 width/height 即内容网格。这是 docs/02 已有语义的显式化，不改变接口主体。
- MARD 数据 code 统一按 docs 显示规则补零为 `A01`/`ZG08`；原始上游写 `A1`/`ZG8`。
- 上游两个 MIT 源中 `Q04` 与 `R11` 共用同一 hex `#FFEBFA`，为真实重叠项；validator 保留 code 唯一、对重复 hex 仅警告。
- `countByColor` 可接收可选 `LoadedPalette` 以输出 hex；Worker 回传 `Pattern`，统计在 UI 侧计算。
- 数据流水线与核心代码均以文件为单位拆分，`src/` 与 `data/scripts/` 无超过 400 行文件。
- 交付时工作区尚未初始化 Git 仓库，因此未按 `docs/05` 的“每步一 commit”产生提交历史；阶段 3 如需版本化，可先 `git init` 后按功能拆分补交。
