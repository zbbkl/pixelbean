## 1. 方案 A（立即，安全，确定性）—— 先实现并验证

### A.1 默认关闭

- `src/app/options.ts`：`defaultSettings.removeBackground = false`。

### A.2 可信度兜底（`src/core/pipeline/subject.ts`）

```ts
export interface SubjectResult {
  cells: Uint8ClampedArray;
  mask: Uint8Array;
  bbox: { x0:number;y0:number;x1:number;y1:number } | null;
  reliable: boolean;
  subjectRatio: number;           // 主体像素/总像素
  largestComponentRatio: number;  // 最大主体连通域 / 主体像素
}
```

在现有 `dropTinyIslands(fillSmallHoles(mask,…))` 之后新增指标计算：

```ts
function subjectMetrics(mask, w, h): { subjectRatio, largestComponentRatio } {
  const total = w*h;
  const subjectPx = count(mask===1);
  const comps = labelConnected(mask===1);            // 4 连通
  const largest = max(comps.map(size));
  return {
    subjectRatio: subjectPx / total,
    largestComponentRatio: subjectPx ? largest / subjectPx : 0
  };
}
```

**判定不可信 `reliable=false`（满足任一即回退全主体）**：
- `subjectRatio < 0.15`（主体太小 / 被吞）；或
- `largestComponentRatio < 0.55`（主体被打碎）；或
- `bbox` 覆盖 ≥ 0.98 全幅（几乎无背景可去 / 整图被判背景）。

`reliable=false` 时返回 `{ cells: 原图, mask: 全 1, bbox: 全幅, reliable:false, … }`。

### A.3 管线接入（`src/core/pipeline/index.ts`）

```ts
// 在 convertPipeline 最前（downsample 前）：
if (options.removeBackground) {
  const sub = extractSubject(source, …);
  if (sub.reliable) {
    source = { width: source.width, height: source.height, data: sub.cells };  // 背景 alpha=0
    subjectMask = downsampleMask(sub.mask, source.width, source.height, contentW, contentH);
    contentBox = mapBBoxToGrid(sub.bbox, sourceW, sourceH, contentW, contentH); // 供 contain
  } else {
    // 不可信 → 当作未去背景（等价 removeBackground=false，跳过后续去背景逻辑）
    removeBackgroundEffective = false;
  }
}
// 匹配产出 pattern 后：
if (removeBackgroundEffective) {
  pattern = clearBackgroundCells(pattern, subjectMask);   // mask=0 → 格=-1
}
// 方形底板 contain：
if (removeBackgroundEffective && options.contain) {
  pattern = placeContain(pattern, boardW, boardH, contentBox);  // 用主体盒而非整图
}
```

> 现有 `subject.ts` 已含 `downsampleMask`；新增 `mapBBoxToGrid`、`clearBackgroundCells`（可放到 `subject.ts` 或 `contain.ts`）。**凡 `subjectMask[cell]=0`，该格置 -1 并从色数/限色/合并/统计中剔除（`clearBackgroundCells` 后用现有统计对 -1 的自然跳过即可——确认 `clusterLimitV2`/`mergeAdjacent`/统计均忽略 `cells<0`）。**

## 2. 方案 B（稳健去背景）—— 实现 + 门禁通过才默认开启

> B 是让「默认开启」成立的算法；**但 A 的兜底让它永远安全**。B 的核心 = 弃用「单一颜色距离」判据，改用**多尺度结构梯度**做背景/主体的边界屏障。

### B.1 多尺度结构梯度屏障（`subject.ts` 内新增，替换 `floodColorBackground` 的判据）

问题重述：狗/兔白身与白底同色，且柔光使**单像素**梯度很小 → 现有 `maxNeighborDelta(…)>edge` 永不触发。改用「**局部均值 vs 周围环均值**」在多尺度取脊：

```text
function ridge(p): // p 是像素索引
   best = 0
   for s in [2,4,8]:                       // 半窗半径
     innerMean = meanLab( p 的 (2s+1)x(2s+1) 邻域 )
     ringMean  = meanLab( 邻域外一圈，厚 s 的环 )
     best = max(best, ΔE76(innerMean, ringMean))
   return best
```

`floodColorBackgroundV2`：
```text
bgLab = borderMedianLab(...)               // 仍用于颜色判据（收紧 tol）
seed: border 像素中 ΔE(px,bgLab) <= tol(6) 者
flood 扩展（4 邻）：n 判为背景 当且仅当
   ΔE(px(n), bgLab) <= tol                  // 颜色够接近背景
   AND ridge(n) <= edgeScale(12)            // 且不是主体轮廓脊
   AND data[n].alpha >= 128
```
> 关键：柔和轮廓在 `s=4/8` 处 `innerMean vs ringMean` 会形成可测的脊（即使单像素梯度小），于是洪水在轮廓处停下，**白色头部被留在主体内**。`tol` 收小（6）避免纯颜色吞主体（原来 13 太松）。

**预计算**：`ridge` 可用 `srgbRgbToLab` + 盒滤波（前缀和）在 O(w·h) 内求 `innerMean`/`ringMean`，确定性强。

### B.2 主体装配（可选，增强抗碎）

```ts
function assembleSubject(mask, w, h, minAreaFrac=0.002):
   comps = labelConnected(mask===1)
   keep = comps 中 size >= minAreaFrac*w*h 的连通域
   // 若最大连通域占比 < 0.55 → 判不可信（回退，交给 A.2）
   mask2 = union(keep)
 返回 mask2
```

`extractSubjectResult` 统一在 `assembleSubject` 后跑 `subjectMetrics` 判定 `reliable`；不可信 → 回退全主体。**确保默认开启也不会吞主体/空图纸。**

### B.5 与现有管线叠加

- B 仅替换 `subject.ts` 内部的背景判定/装配；`extractSubject` 对外签名、`reliable`/`mask`/`bbox` 契约不变。
- `removeBackground=true` 时链路 = `extractSubject(B) → 主体盒 contain → 像素化 → 匹配 → clearBackgroundCells`。其它（抖动/限色/后处理/特征保护）叠加去背景都要走 `combo.mjs` 不崩（现有已验，B 只改判据，不新增分支）。
