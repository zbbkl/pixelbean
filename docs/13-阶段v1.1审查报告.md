## 3. post/* 算法逐行对照 docs/03 §9

### 3.1 speckleClean（§9.1）— 一致
4-邻域连通域标记、`(格数 asc, 色索引 asc)` 排序、边界邻居多数色、`ΔE2000 ≤ ΔEthr` 才合并、单遍不迭代 —— 与伪代码逐条吻合。保护语义正确：只动 `≤noiseMax` 小域，深瞳孔（ΔE 大）天然保留。`-1` 空格不计入边界邻居（不能并入空格），合理。

### 3.2 shadowSimplify（§9.2）— 一致
锚点选取：最低 L 色若 C<8（灰）即锚点，否则取 `L<45 且 C 最小`；`L<45` 阈值、level1=18 / level2=28 阈值、彩色暗部因 ΔE 远保留 —— 全部吻合。无暗色（最暗 L≥45）→ 返回原 pattern（幂等），对应 §9.2 步骤 4。

### 3.3 clusterLimit（§9.3）— 一致 + 一处 P1 已修
- 色相族分组：`hue=atan2(b,a)`、`C<8` 判灰族、相邻差 `≤20°` 且双方 `C>8` 才并族、灰系自成一族 —— 吻合。
- **族跨度 ≤60°**：docs/03 §9.3 只写「相邻差 ≤20°」，未写跨度上限；实现额外加 `span+delta ≤60°`。此前为裸魔法数 `60` 且无注释（与 docs/11 自述「已在代码注释说明」不符），**已补注释并提为常量 `MAX_FAMILY_SPAN`**。
- 族内分层 ≤3、quota=round(占比×K)、保留最亮/最暗再等距选代表、重匹配在保留集内 —— 吻合。
- **P1 修复**：`protect=true` 时保护集最多含 {暗, 亮, 饱和} 3 色；当 `K < 保护色数量`（自定义 K=2/3）时 `removeUntilLimit` 无法删除任何保护色 → 返回 `>K` 色，违反 docs/01 §9「色数统计 ≤ 设定值」。已修：保护色按重要性排序（暗>亮>饱和），兜底按「饱和→亮→暗」顺序舍弃，保证 `≤K`。见 §5。

### 3.4 outline（§9.4）— 一致（含已记录残余风险）
- 描边色选择：已用最深色优先（L≤30），否则允许新增 1 个板内深色（L≤25、C≤60），UI 明示「K+1」—— 吻合。
- 边缘判定「对每个格若任一邻居 \|ΔY\|>τ 标记」、落色「被标记的前景内容格整格改色」、`-1` 空格不改色 —— 与伪代码逐条吻合。
- **「两侧 1px」**：内容/内容高对比交界两侧都被标为轮廓（各自 1px），是「对每个格…标记」+「前景内容格整格改色」的直接结果，**代码忠实于伪代码**；视觉上是 2px 交界，docs/11 已列为残余风险。见 §6。
- **非幂等**（本次新证）：`outline(outline(p)) ≠ outline(p)`。以 `[-1, 白, 白, 暗, 暗, -1]` 为例，第一次得到 `[-1, 白, 暗, 暗, 暗, -1]`，第二次再吃一格白 → `[-1, 暗, 暗, 暗, 暗, -1]`。docs/11 的「幂等」表述不准确——其 `is deterministic` 用例测的是同输入两次输出一致（确定性），并非幂等。§9.4 步骤 5 的「幂等」仅覆盖「全图 1 色 / 无边缘」两种退化情形，代码对这两种情形确为幂等。

## 6. 偏差记录 / 残余风险

1. **outline「两侧 1px」+ 非幂等（P2，待真实图裁决）**：内容/内容高对比交界两侧均染轮廓色，视觉 2px；重复执行会继续外扩。代码忠实于 §9.4 伪代码，未做单边改动（改单边需前景/背景分割，超出 v1.1 数据模型）。建议：若用户验收要求严格「1px 可数格」，需在 §9.4 明确「只染较亮侧」并新增前景/背景语义；否则在 docs/03 补一句「交界两侧各 1px、语义无外扩」。docs/11「幂等」措辞应更正为「确定性」（其测试实为 determinism）。
2. **clusterLimit `representativesForFamily` 在 `layerLimit===1` 时取「用量最多」色**，docs §9.3 步骤 3 写「保留最亮/最暗」；配额为 1 时二者无法兼得，取用量最多是合理兜底，属轻微偏差（P2）。
3. **Perler 无 transparent**（`perler-standard.json` 103 全 solid），docs/04 §7.2 举例「如 Perler 透明 P-Clear」未落地；主数据源 beadcolors perler.csv 无透明项，属数据完整性缺口（P2，后续官方转录可补）。
4. **无真实角色图**：`.tools/test-img/` 仅有 Codex 用内置样例产出的两张结果图（`result-v1-old.png` 27 色 / `result-v1.1-cartoon.png` 7 色，1892×2552 图纸），无用户角色原图。四项人工验收（黄系层数/暗部单层/孤立点/轮廓）**无法以目标图闭环**，已以内置样例 + 单测（T13–T16）+ 浏览器实测替代，并如实标注。
