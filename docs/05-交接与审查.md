## B. 阶段 3（Claude Code）：审查清单（务必"跑起来"审查，禁止只看代码）

1. **启动**：`npm install && npm run dev`，无控制台报错；`npm test` 全绿。
2. **DoD 复核**：逐条跑 docs/01 §5 的清单与 §6 的 T1–T12 测试用例，如实记录。
3. **算法正确性审查**（对照 docs/03）：
   - ΔE2000 逐行与 Sharma 式核对；跑校验向量。
   - 降采样边界（floor/ceil 覆盖、1 格宽/高、alpha 阈值）无 off-by-one。
   - 锁宽高比公式在"超宽 4000×400→长边 29"下高度=3 且不拉伸。
   - limit 保护集的实现与 docs 语义一致（保护的是**实际用到的**暗/亮/饱和色）。
4. **性能**：Worker 线程无泄漏（快速连续调参）；150k 格渲染不冻结主线程；大图路径内存峰值合理。
5. **工程纪律**：无 >400 行文件；`src/core` 无 DOM/React 依赖；无 `any` 泛滥；无 `Math.random` 进算法；deterministic fixture 无随机。
6. **依赖审计**：运行时依赖清单符合 docs/02 §1；新增依赖必须写进 docs 并说明理由。
7. **数据红线**：git grep 确认没有来自 AGPL/GPL/无证仓库的色表或代码片段（对照 docs/00/04）；palettes JSON 的 license/source 字段齐全。
8. **可访问性与细节**：色号文字对比度、按钮键盘可达、悬停信息在触屏的替代（点击）。
9. **部署文档**：纯静态 `dist/` 部署到 GitHub Pages/Vercel/Nginx 的分步说明 + base path 坑（GitHub Pages 子路径）。
10. 输出：`阶段 3 审查报告.md`（问题清单 P0/P1/P2 + 修复提交记录 + 部署文档）。
