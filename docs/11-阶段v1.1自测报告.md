## 对 docs 的偏差与实现说明

- `.tools/test-img/` 无输入图：本报告改用内置样例并如实标注；不把替代图当作用户验收通过。
- Perler 使用 beadcolors 的零售产品号（如 `80-15179`），未伪造 docs 示例中的 `P01…` 短码；docs/00 已指出 P01-P70 是社区自造码。
- Perler/Hama 的 `quality` 标记为 `community-legacy`：beadcolors 与 hank/beadmachine 的批次 hex 存在 21 条 ΔE>10 差异（完整表在 crosscheck report），按“诚实标注”处理，未冒充 `community-verified`。
- `clusterLimit` 的实现把“同族”定义为相邻 hue 差 ≤20° 且族跨度 ≤60°，并把每族代表层压到 ≤3，用于落实 docs/01 的“同色相族 ≤3 层”验收；docs/03 §9.3 只给了相邻差规则，未写跨度上限，已在代码注释说明。
- 实现中发现并修复 `xyzToLab` 分段公式漏除 116 的 v1 bug（深色 Lab 错误），已单独提交并补回归测试。
- 模式/后处理参数仍全部为 DOM-free 的 `src/core/post/`；UI 只做参数映射，`modePresets` 为纯数据。

## 残余风险

- Perler/Hama 色板为社区来源，与实物/官方色卡仍有批次色差；UI 已标“社区旧表”，后续可做官方转录升级 quality。
- 自动描边会把高对比边界的左右两格都标记为轮廓（各自 1px），语义上无外扩但视觉上可能是 2px 交界；等待真实角色图人工确认是否满足“1px 可数格”。
- `.tools/test-img/` 真实角色图未到位，四项人工验收尚未以目标图闭环。
