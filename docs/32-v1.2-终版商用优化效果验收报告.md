## 1. 方法

- 兔子原图：`.tools/diag-v12final/rabbit.rgb`（8 字节头 + RGBA，1104×1424，自写解析器渲染为 PNG 供目检）。
- off 路径 = v1.2.1 照片默认（`mode:'average'` + features）；on 路径 = v1.2-final 照片默认（`mode:'dominant'` + features + E2–E5，自动含 `mergeAdjacent`）。

## 3. 特征还原（验收点 1）

**原始兔子关键特征**（源图渲染，见 `.tools/diag-v12final/rabbit-ref2.png`）：绿瞳 + 深色瞳孔、细嘴线、蓝紫耳尖、白色身体 + 浅蓝肚；额头仅一枚极淡粉色印记（非强红点）。

**on 版输出**（`rabbit-on.png`）：
- 绿瞳 + 深色瞳孔：✅ 保留（两只眼睛清晰，虹膜+瞳孔）。
- 嘴部细线：✅ 保留（深色微笑线）。
- 蓝紫耳尖：✅ 保留（两耳尖色块）。
- 额头印记：⚠️ 原图即极淡（非强“红点”），78 格下仅微弱呈现；`docs/30` 亦标注该项目需人工放大复核。

**off 版对照**（`rabbit-off.png`）：同保留眼/嘴/耳尖，但身体/腿部出现更多细小灰调杂斑（发虚感），即本版要消除的“画面发虚/杂色”。

> 关于验收标准中的“额头红点”：**本兔子源图不存在强红点**（仅淡粉印记）。若以“红点”为强判定，则本项目样本不支持；以“眼睛/嘴/耳特征完整无畸变”为准判定——均达标。建议后续以一张确含强红点/粉色斑的角色图复测该子项。

## 4. 色块质量（验收点 2）

- 色数 40→34（−15%），≤2 格孤立小块 453→347（−23%）：可见的细碎孤立色块显著下降，块面更“统一”。
- 目检 `rabbit-on.png`：白身/灰影区过渡更干净，边界无 1 格插花杂色；`rabbit-off.png` 在腿/身交界处有零星灰点。
- 卡通 on（`cartoon-on.png`）：蓝/白角色高对比、块面干净，无脏污过渡色（27 色，较 off 33 色更少）。

## 5. 边缘轮廓（验收点 3）

- 主体边缘更“硬”：dominant+E4 柔边收敛把主体/背景交界模糊格归属到主体侧，`rabbit-on.png` 耳尖/身体外缘更贴主体色，无“蒙雾”柔边。
- off 版身体-背景交界因 average 混色出现软边晕（发虚），on 版显著缓解。
- 结论：符合“主体边界清晰、无柔边发虚、可拼豆”要求。

## 6. 残余建议（人工）

- 兔子瞳孔/耳尖粉、卡通 609×814 在高分辨率下的最终目检（本版截图尺度 78 格，人工放大复核最优）。
- “额头红点”强判定需一张确实含强红点的角色图复测（本兔子源图无强红点）。
- regionClean 仍为 opt-in 默认关；outline 连续性微调未接入默认（维持 docs/27 §6.2 / docs/30 决议），如需更“硬边”用户可手动开 outline（可选装饰）。
