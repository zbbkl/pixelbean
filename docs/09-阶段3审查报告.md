## 4. 代码审查逐项结论（docs/07 §3.3）

### 4.1 算法正确性 ✅
- **CIEDE2000**（`src/core/color/ciede2000.ts`）逐行对照 Sharma 2005：`G`、`a'`、`h'`、`ΔH'=2√(C₁'C₂')sin(Δh'/2)`、`T`、`R_T`、`S_L/S_C/S_H` 均一致；`tests/unit/ciede2000-vectors.ts` **34 组官方向量齐全**，断言 `|Δ−期望|<0.0005` 全过。
- **sRGB↔线性**（`srgb.ts`）：IEC 61966-2-1 分段常数（0.04045/0.0031308/1.055/2.4）正确；往返 8bit 量化误差 ≤1（有单测）。
- **线性→XYZ→Lab**（`lab.ts`）：D65 矩阵与白点（Xn=0.95047/Yn=1/Zn=1.08883，0–1 标度）与 docs/03 §3.2 一致。
- **downsample 边界**（`downsample.ts`）：`x0=floor(gx·sw/W)`、`x1=max(x0+1, floor((gx+1)·sw/W))` 与 docs/03 §2.1 一致，保证每格至少采样 1 像素（`n≥1`，无除零）；alpha 阈值（≤0 垫底、≥128 用原色、中段 sRGB 混合）与 docs/03 §1 一致。
- **geometry**（`geometry.ts`）：`deriveLongEdgeGrid(4000,400,29)=29×3` 无 off-by-one；`deriveContainContent` 等比 contain 正确（有单测）。
- **colorLimit 保护集**（`colorLimit.ts`）：保护**实际用到**的暗/亮/饱和关键色（按源代表色 Lab 的 L*/C* 均值排序，4%/4%/3% 用量），再按用量取余下名额，淘汰格重匹配到保护集内 ΔE2000 最近色——与 docs/03 §4 语义一致（有单测）。

### 4.2 性能与内存 ✅（如实记录）
- **Worker 无泄漏/无过期回跳**：`App.tsx` 的 `seqRef` 递增 + `worker.onmessage` 校验 `message.seq === seqRef.current`，过期结果丢弃；快速连续调参（T8/T9 多次转换）未出现旧结果回跳。
- **150k 格渲染不冻结**：387×387=149,769 格，转换耗时 6.6s，canvas 实际渲染（采样非白像素 40,000/40,000），无 pageerror、无主线程冻结。
- **大图峰值内存**：12000×12000（10.55MB）→ 浏览器解码位图（~576MB RGBA）→ 缩样 4000×4000（64MB `ImageData`）→ worker 转换，上传+解码 5.6s 完成，未 OOM。
- **200 格长边**：788ms（<3s），满足 DoD 第 7 项。

### 4.3 安全与隐私 ✅
- 纯前端本地处理：转换在 Web Worker + Canvas，`dist/` 无任何上传图片的后端代码，图片不出本机。
- 无 `dangerouslySetInnerHTML`（`git grep` 为空）；色表/色名均经 React 文本节点或 Canvas 绘制，无 HTML 注入面。
- 自定义色表导入：`loadPalette` 全量校验（schema/重复 code/hex-rgb 一致/kind 合法），错误以中文提示（`PaletteImport` 显示）。

### 4.4 健壮性 ✅
- 损坏图片：`img.onerror → reject('图片解码失败')`，UI 显示错误。
- 超大图：单边 >12000 拒绝载入；网格 >150,000 格提示上限（T12b 实测）。
- 超小图：16×16 放大到 64 不崩（T6）。
- 空色表/非法 JSON：`loadPalette` 抛 `PaletteValidationError`；`transparent` 色可不给 hex。

## 8. 残余风险

1. **真实照片/表情包像素级人工抽验**：golden fixture 与自动化 e2e 覆盖的是合成图；真实照片效果需人工抽验（本轮用合成渐变/纯色/线稿图覆盖转换链路）。
2. **屏幕色 ≠ 真实豆色**：图纸以 `code` 为准，UI header 已提示「hex 仅近似，以 code 为准」；MARD hex 为 `community-verified` 近似值，未宣称官方精确色。
3. **150k 格转换 6.6s > 3s**：满足 DoD 第 7 项「**或**显示进度且可取消」（有「转换中」badge + 取消按钮）；若需 <3s 需对 15 万格降采样做进一步优化（如分块/WASM），属 P2。
4. **超大图内存峰值**：12000×12000 解码位图 ~576MB，实测可完成但接近主流设备内存上限；已在载入端做「>12000 拒绝 + 4096 边缩样」双保险。
