## 3. 代码审查结论

### 3.1 PreviewCanvas 手势数学
- **双指捏合锚点**：`gx=(center−PADDING−startPan)/startZoom` 用**冻结的 startZoom/startPan**（非实时 view），再 `panX=center−PADDING−gx·nextZoom` 保持锚点跟随中点，避免反馈漂移 ✅；`nextZoom=clamp(startZoom·ratio, 1, 96)` ✅。
- **点按 vs 拖拽**：4px 阈值区分（`hypot(dx,dy)>4` 置 `moved`），`noDrag && pointerType==='touch'` 才触发 tap → hover ✅。
- **双击防页面缩放**：`touch-action: none`（workspace.css:113）作用于 `.canvas-scroll` + `onDoubleClick preventDefault` ✅；但发现**双重触发 bug**（见 §4-1）。
- **`hitCellAtClient`**：pan 后坐标换算 `floor((x−PADDING−panX)/zoom)` 正确 ✅。

### 3.2 MobileNav 状态保留
三段切换只改 `mobileSection` 本地 state 与 CSS 显隐（`mobile-section-*`），`source/settings/pattern/stats` 始终在 `useAppState` 同一 reducer 中，不重建 ✅；`aria-label`/`aria-current` 到位 ✅。

### 3.3 mobile*.css iOS 细节与断点
- `100dvh` 回退 `100vh` ✅；`viewport-fit=cover` ✅；底栏 `env(safe-area-inset-bottom)` ✅；全屏 `env(safe-area-inset-top/bottom)` ✅。
- 输入控件 `font-size:16px; min-height:44px` 防 iOS 聚焦缩放 ✅；按钮 `touch-action:manipulation`，画布 `touch-action:none` ✅；`.canvas-scroll overscroll-behavior:contain` ✅；未用 `user-scalable=no` ✅。
- 断点：≥1024 三栏 / 768–1023 两栏可折叠 / ≤767 单栏三段 / ≤480 紧凑，与 docs/14 §1 一致 ✅。
- `@media print` 隐藏移动控件 ✅。

## 5. P2（记入，不修）

1. **捏合中途冻结**：单指先拖拽（`moved=true`）再按下第二指时，`gestureRef` 被置空，两指 move 既不 pan 也不 pinch（内容暂时冻结），抬起一指恢复。属罕见交互，且是「防缩放跳变」的有意取舍。
