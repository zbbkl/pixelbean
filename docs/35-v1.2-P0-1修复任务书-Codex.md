## 1. 修复规格（P0-1 唯一改动点）

**文件**：`src/core/pipeline/downsample.ts`
**问题**：`downsampleDominantV2` 的空桶平滑（empty-smooth）权重式里，`LAB_NEIGHBOR_WEIGHT[0]=1` 导致**亮度（L）轴方向的邻居权重恒为 0**，空桶平滑只在 a/b（彩度）方向传播，完全不跨亮度桶 → 柔和渐变（T1 奶龙类）出现亮度阶跃带纹。

**改动 A**（`downsample.ts:206`）：常量

```ts
// before
const LAB_NEIGHBOR_WEIGHT = [1, 0.5, 0.5] as const;
// after（各轴距离 1 的衰减一致）
const LAB_NEIGHBOR_WEIGHT = [0.5, 0.5, 0.5] as const;
```

**改动 B**（`downsample.ts:~282` 的 `weight` 计算，位于 `for (let dl...)` 三层循环内）：把「中心轴 = 权重值、偏移轴 = 1-权重值」的错误式改为「中心轴 = 1、偏移轴 = 权重值」（对称衰减）：

```ts
// before
const weight =
  (dl === 0 ? LAB_NEIGHBOR_WEIGHT[0] : 1 - LAB_NEIGHBOR_WEIGHT[0]) *
  (da === 0 ? LAB_NEIGHBOR_WEIGHT[1] : 1 - LAB_NEIGHBOR_WEIGHT[1]) *
  (db === 0 ? LAB_NEIGHBOR_WEIGHT[2] : 1 - LAB_NEIGHBOR_WEIGHT[2]);
// after（中心轴满权=1，偏移轴衰减=0.5；三轴对称）
const weight =
  (dl === 0 ? 1 : LAB_NEIGHBOR_WEIGHT[0]) *
  (da === 0 ? 1 : LAB_NEIGHBOR_WEIGHT[1]) *
  (db === 0 ? 1 : LAB_NEIGHBOR_WEIGHT[2]);
```

> **为什么这样改**：修复后，`(Δl=±1,Δa=0,Δb=0)` 的邻居贡献 `0.5`（原来=0），`(Δl=±1,Δa=±1,Δb=0)` 贡献 `0.25`（对称衰减），使稀疏亮度桶能从相邻亮度桶借量，消除亮度方向的一侧断层；同时三者合计仍受 `emptySmooth`（默认 0.5）与 `counts[neighbor]` 缩放，**不改变** `score` 的量级（仍是「次数 + 邻桶借量」）。
> **红线**：`emptySmooth` 默认值、`LAB_BUCKETS_L/A/B`、桶索引 `labBucket`、`n<4` 回退 `averageRegionRgb`、返回的 `Uint8ClampedArray` 结构与 `downsample()` 对外签名**一律不变**。只允许上述两处字面改动。
